# jules-demo-build

This repository is used for a live demonstration of [Google Jules](https://jules.google.com), an asynchronous AI coding agent.

## Demo Scenario

Jules will be assigned an issue to build a Todo List web app from scratch — a single `todo.html` file that runs directly in the browser with no server required.

## What Jules will build

- Add and remove todo items
- Mark items as complete
- Display total and completed item counts
- Show an empty state message when the list is empty
