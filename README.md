# jules-demo-build

此 Repository 用於 [Google Jules](https://jules.google.com) 的現場示範。

Jules 是 Google 推出的 AI 非同步程式碼代理人，能夠自主完成開發任務並送出 Pull Request。

## Demo 情境

指派 Issue 給 Jules，讓它從零開始建立一個待辦清單 Web App（單一 `todo.html` 檔案，可直接用瀏覽器打開，不需要伺服器）。

## Jules 將會建立的功能

- 新增與刪除待辦事項
- 勾選項目標記為完成
- 顯示全部數量與已完成數量統計
- 清單為空時顯示提示訊息



Jules 提示詞

 建立一個可以直接用瀏覽器打開的待辦清單 App（單一 HTML 檔案，不需要伺服器）。

  功能描述：
  - 輸入文字後按「新增」或 Enter 可新增待辦事項
  - 每個項目有勾選框，勾選後顯示為完成（文字加刪除線）
  - 每個項目有「刪除」按鈕，點擊後移除該項目
  - 頁面顯示「全部數量」與「已完成數量」的統計
  - 若清單為空，顯示提示文字

  技術規格：
  - 使用 HTML + CSS + JavaScript
  - 不使用任何外部框架或函式庫
  - 介面簡潔，使用繁體中文
