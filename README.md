# jules-demo-build

此 Repository 用於 [Google Jules](https://jules.google.com) 的現場示範。

Jules 是 Google 推出的 AI 非同步程式碼代理人，能夠自主完成開發任務並送出 Pull Request。

## Demo 情境

指派 Issue 給 Jules，讓它從零開始建立一個待辦清單 Web App（單一 `todo.html` 檔案，可直接用瀏覽器打開，不需要伺服器）。

## Jules 將會建立的功能

- 新增與刪除待辦事項
- 勾選項目標記為完成
- 顯示全部數量與已完成數量統計
- 清單為空時顯示提示訊息
